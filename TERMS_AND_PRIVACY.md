2. Privacy Policy

Data Collected

Good News Co. collects and stores only the minimal data necessary to function across multi-server environments:

Server IDs & Channel IDs: Stored locally in state management files to deliver scheduled daily news articles to designated channels.

All collected configuration data is used strictly for bot operations (delivering daily news dispatches). We do not collect personal user messages, track user behavior, or sell, share, or monetize any server data.
